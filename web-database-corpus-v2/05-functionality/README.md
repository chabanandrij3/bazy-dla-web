# Функціональність

## Повні локальні файли

- [mdn__content](mdn__content/) — файли на місці
- [GoogleChrome__lighthouse](GoogleChrome__lighthouse/) — файли на місці

У папках вище збережено структуру вихідних репозиторіїв: документацію, код, дані, приклади, тести та ліцензії. Цей стислий огляд допомагає знайти потрібну частину; для точних значень і API відкривайте локальні файли джерел.

## Практичний огляд


**Джерела:** [MDN Web Docs](https://github.com/mdn/content) і [Google Lighthouse](https://github.com/GoogleChrome/lighthouse). Офіційні матеріали: [MDN Learn Web Development](https://developer.mozilla.org/en-US/docs/Learn_web_development), [Chrome — Lighthouse](https://developer.chrome.com/docs/lighthouse/), [Lighthouse CLI](https://github.com/GoogleChrome/lighthouse#using-the-node-cli).

## Зведені правила

1. Кожен видимий елемент керування має виконувати очікувану дію. Перевіряйте весь шлях: запуск, завантаження, успіх, помилку й повторну спробу.
2. Використовуйте нативні можливості HTML і браузера там, де вони відповідають завданню. Так простіше забезпечити роботу клавіатурою, історію переходів і підтримку різних пристроїв.
3. При повільній мережі користувач має розуміти, що відбувається. Не губіть введені дані через тимчасову помилку.
4. Продуктивність впливає на фактичну працездатність сайту: повільне завантаження й затримка реакції можуть зірвати виконання завдання.

## Що додає Lighthouse

- **Автоматичний аудит URL:** швидкість, доступність, технічні практики та SEO збираються в один звіт із посиланнями на пояснення конкретних проблем.
- **Відтворювані результати:** інструмент можна запускати в Chrome DevTools, командному рядку або як Node-модуль. Це зручно для порівняння версій сторінки.
- **Дані продуктивності:** Lighthouse показує вузькі місця завантаження й відгуку, яких не видно з документації API MDN.
- **Межа автоматизації:** успішний аудит не перевіряє бізнес-логіку, фактичне збереження даних, оплату чи правильність результатів пошуку.

## Перевірка функцій

- Складіть коротку таблицю сценаріїв: дія → очікуваний результат → фактичний результат → стан помилки.
- Пройдіть кожен основний сценарій мишею і клавіатурою, на вузькому екрані та при нестабільному з'єднанні.
- Запустіть Lighthouse на типових сторінках, а не лише на головній.
- Для сумісності вебможливостей між браузерами див. [Web Platform Tests](../09-supplements/README.md#4-web-platform-tests).
